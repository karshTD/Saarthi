# Deploying Saarthi (free tiers)

Architecture: **Neon** (Postgres) <- **Render** (FastAPI backend) <- **Vercel** (Next.js frontend).

| Piece | Free tier notes |
|---|---|
| Neon | Free Postgres that does not expire. (Render's free Postgres is deleted after 30 days, so don't use it.) |
| Render | Free web service. Sleeps after ~15 min idle; the first request then takes ~30-60 s. Open the site once before a demo. |
| Vercel | Hobby plan is free for personal/non-commercial use. |
| GitHub Actions | Free for the CI in `.github/workflows/ci.yml`. |
| Anthropic API | **The only paid part, and optional.** No key = built-in templates, labelled `generated_by: template`. |

## 1. Database (Neon)
1. Create a project at neon.tech. Copy the **direct** connection string (it ends in `?sslmode=require`).
2. Keep it for step 2. `postgres://` and `postgresql://` are both accepted.

## 2. Backend (Render)
1. Push this repo to GitHub.
2. Render -> New -> **Blueprint** -> pick the repo. It reads `render.yaml`.
3. Fill in the prompted env vars:
   - `DATABASE_URL`: the Neon string.
   - `ACCESS_CODE`: any shared passphrase you'll give to demo users.
   - `CORS_ORIGINS`: put a placeholder (`http://localhost:3000`) for now.
   - `LLM_API_KEY`: leave empty to stay free, or paste an Anthropic key.
4. Deploy. On start it runs `alembic upgrade head` and (because `SEED_ON_START=true`) loads
   synthetic demo data. Open `https://<service>.onrender.com/api/health` and expect `{"status":"ok",...}`.

## 3. Frontend (Vercel)
1. Vercel -> Add New Project -> same repo. Set **Root Directory** to `frontend`.
2. Environment variable: `NEXT_PUBLIC_API_URL` = your Render URL (no trailing slash).
3. Deploy and note the Vercel URL.

## 4. Close the loop
1. Back in Render, set `CORS_ORIGINS` to the Vercel URL (no trailing slash) and redeploy.
2. Open the Vercel URL -> Dashboard. It asks for the access code once (stored in your browser).
3. Check: the header shows "live", Generate lesson shows `generated by: seed` the first time
   (the demo session already has a lesson), and class counts read 3 / 4 / 3.

## Troubleshooting
- **CORS error in the browser console:** `CORS_ORIGINS` doesn't exactly match the Vercel URL.
- **"backend unreachable":** Render is waking up (wait a minute) or `NEXT_PUBLIC_API_URL` is wrong. It
  is baked in at build time, so redeploy the frontend after changing it.
- **Asked for the access code repeatedly:** it doesn't match `ACCESS_CODE`. Clear `saarthi_access_code`
  from the browser's local storage and re-enter.
- **429 Too Many Requests:** the AI rate limit (`AI_RATE_LIMIT_PER_MINUTE`, per IP) was hit; wait a minute.

## Real data
Never deploy real student data to this public demo. `SEED_ON_START=true` loads synthetic data only.
